# Nanaveda — Traditional recipes and formulas for healthy consumables.

This folder is the central repository for the Nanaveda project. All outputs, research, assets, and documentation related to the project live here.

## Folder Structure
- **PROJECTS/** — Active project files
- **OUTPUTS/** — Completed outputs for delivery
- **TEMPLATES/** — Reusable templates
- **LOG/** — Session logs and progress tracking
- **RESEARCH/** — Ingredients, formulations, and reference material
- **ASSETS/** — Images, media, and non-text resources
